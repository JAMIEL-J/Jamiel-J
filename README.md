## Flagship Systems

### 🔹 [Vizzy Analytics](https://github.com/JAMIEL-J/Vizzy-Analytics) *(Peer-Reviewed & Published in IJRASET)*
Governed NL-to-SQL analytics platform. Converts natural language queries into validated SQL, automated data visuals, and executive narratives.
* **Performance**: Achieved **104ms p95 latency** on **1M rows** via a DuckDB-first pipeline (3.34x faster than Pandas with 47.7MB peak heap).
* **Safety & Governance**: SQLGlot AST validation to prevent hallucinated queries; JWT/RBAC role gates and an append-only audit trail.

`FastAPI` `DuckDB` `React 19` `Groq (Llama 3.3-70B)` `SQLGlot` `SQLModel` `Recharts` `Zustand`

### 🔹 [DNA Desktop Voice Assistant](https://github.com/JAMIEL-J/DNA-Desktop-Assistant-)
Zero-cloud, low-resource voice assistant designed for constrained local hardware (i3-1134G4, 8GB RAM, no GPU).
* **Architecture**: Three-state finite state machine (Sleeping → Active → Processing) with hardware mic-gating to eliminate feedback loops.
* **Latency Optimization**: Regex-first intent routing bypasses LLM inference for system commands; utilizes INT8 quantized `faster-whisper` and Piper TTS.

`Python` `faster-whisper` `Piper TTS` `OpenWakeWord` `Gemma / Gemini API` `SQLite` `DuckDB`
